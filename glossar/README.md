# Glossarbeiträge

In Aufgabe 3 legt jede Person auf einem eigenen Branch eine **eigene** Markdown-Datei an, zum Beispiel:

```text
glossar/mein-githubname.md
```

Jede Datei erklärt genau einen Git- oder GitHub-Begriff. Dadurch können viele Pull Requests parallel bearbeitet werden, ohne vor der eigentlichen Konfliktübung unnötige Merge-Konflikte zu erzeugen.
