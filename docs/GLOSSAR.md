# Glossar: Git und GitHub

| Begriff | Kurzbeschreibung |
|---|---|
| Git | verteiltes Versionsverwaltungssystem |
| GitHub | Plattform zum Speichern und gemeinsamen Bearbeiten von Git-Repositories |
| Repository | Projektordner inklusive Versionsgeschichte |
| Working Tree | aktuell ausgecheckte Dateien, an denen lokal gearbeitet wird |
| Staging Area / Index | vorgemerkte Änderungen für den nächsten Commit |
| Commit | gespeicherter Schnappschuss ausgewählter Änderungen |
| Branch | eigene Entwicklungslinie innerhalb eines Repositorys |
| `main` | häufig verwendeter Name des Standard-Branches |
| Remote | entferntes Repository, z. B. auf GitHub |
| `origin` | typischer Standardname des Remotes nach einem Clone |
| Clone | vollständige lokale Kopie eines Repositorys inklusive Historie |
| Push | lokale Commits zum Remote übertragen |
| Pull | Änderungen vom Remote holen und in den aktuellen Branch integrieren |
| Merge | Änderungen verschiedener Branches zusammenführen |
| Pull Request | Vorschlag, Änderungen eines Branches in einen anderen zu übernehmen |
| Review | inhaltliche Prüfung und Rückmeldung zu einem Pull Request |
| Issue | Aufgabe, Problem oder Diskussionspunkt im Repository |
| Merge-Konflikt | Git kann konkurrierende Änderungen nicht eindeutig automatisch zusammenführen |
