# Markdown-Cheatsheet

Markdown ist eine einfache Auszeichnungssprache für formatierten Text.

```markdown
# Überschrift 1
## Überschrift 2

**fett**
*kursiv*

- Listenpunkt
- weiterer Listenpunkt

1. erster Schritt
2. zweiter Schritt

[Linktext](https://example.org)

`Befehl im Text`

```text
mehrzeiliger Codeblock
```

> Zitat oder Hinweis

| Spalte A | Spalte B |
|---|---|
| Inhalt | Inhalt |
```

## Aufgabe zum Ausprobieren

Erstelle in deiner Beitragsdatei mindestens:

- eine Überschrift,
- einen fett formatierten Begriff,
- eine Liste mit mindestens drei Punkten,
- einen Inline-Codeabschnitt mit einem Git-Befehl.
