# GitHub-Klassenprojekt: Gemeinsam mit Git arbeiten

Willkommen im Übungsrepository unserer Informatikklasse.

In dieser Einheit lernst du nicht in erster Linie zu programmieren. Stattdessen übst du die Arbeitsweise, mit der Softwareprojekte im Team organisiert werden: **Git** zur Versionsverwaltung und **GitHub** zur Zusammenarbeit.

## Lernziele

Nach der Einheit kannst du ...

- ein Repository von GitHub auf deinen Rechner **klonen**,
- Änderungen mit `git status` und `git diff` überprüfen,
- Änderungen mit `git add` für einen Commit vormerken,
- einen sinnvollen **Commit** erstellen,
- Änderungen mit `git push` auf GitHub veröffentlichen,
- Änderungen anderer mit `git pull` übernehmen,
- einen eigenen **Branch** erstellen und wechseln,
- einen **Pull Request** erstellen, prüfen und zusammenführen,
- ein **Issue** zur Aufgabenorganisation verwenden,
- einen einfachen **Merge-Konflikt** erkennen und lösen,
- die wichtigsten Begriffe von Git und GitHub korrekt verwenden.

## Grundregel für die Zusammenarbeit

> **Erst aktualisieren, dann arbeiten, dann prüfen, dann committen, dann pushen.**

Arbeite bei den Branch-Aufgaben nicht direkt auf `main`, sondern immer auf deinem eigenen Branch.
